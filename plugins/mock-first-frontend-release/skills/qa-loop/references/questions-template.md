# Tester questions template

```markdown
> Purpose: questions back to the testers on their <date> feedback, ready for the owner to send
> Use: owner copies each tester's section into a message; answers come back to the reviewer, who updates the register
> Delete when: all testers have answered (or the owner drops the open items) and the register is updated

# Questions for the testers

## For everyone
1. **Your setup.** Phone model (or browser), OS version, and the build text from <where the app shows it>.
2. …

## For <tester A>
1. **<Short topic> (<CASE-ID>).** <What we need to know, as a question they can answer from memory.> (F-nn)

(Ids are for the owner's copy only; the chat-ready text sent to testers drops them.)

## For <tester B>
…

## Answers we already have (no reply needed)
- **<What they saw> (<CASE-ID>):** <why it happens, in one or two sentences; what to do, if anything>.
```

Write for a non-engineer: what they saw, what they tapped, which screen, roughly when. Offer choices ("did it A, B or C?") when the code allows only a few explanations. One question per unclear item; group items that share one answer.
